# 工程造价清单智能审核 Skill

## 概述

作为从业20年的资深造价工程师，自动审核工程造价清单，输出详细审核报告。

## 工作流程

### 1. 解析清单文件

用户上传 Excel 文件后，使用 `zaojia_auditor.py` 解析清单：
```bash
PYTHONIOENCODING=utf-8 python3 zaojia_auditor.py "<文件路径>" "<建筑类型>" <建筑面积>
```
- 建筑类型：`工业建筑`（默认）或 `民用建筑`
- 建筑面积：如可从文件名或用户描述中提取

引擎自动识别表头列（项目名称/单位/数量/单价等），兼容广联达导出、手工模板等格式。

### 2. 逐条审核单价

对每条子目：
1. 提取材料关键词
2. 通过 **WebSearch** 搜索造价通等获取实时市场价
3. 与内置参考区间（20年经验积累）做双维度对比
4. 标记 🔴严重（>±20%）/ 🟡注意（±10-20%）/ 🟢正常

### 3. 联网查询材料价格

对于单价偏差较大的子目，使用 WebSearch + WebFetch：
- 搜索 `site:zjtcn.com <材料名称> <规格> 价格`
- 搜索 `site:100xw.cn <材料名称> 2026年 市场价`
- 提取页面中的价格数字
- 与清单单价对比验证

### 4. 工程量指标分析

汇总计算并与参考指标对比：
- 钢筋含量 (kg/m²)
- 混凝土含量 (m³/m²)  
- 平米造价 (元/m²)
- 各分部造价占比

### 5. 生成审核报告

输出包含 3 个 Sheet 的 Excel 报告：
- **审核摘要** — 总造价、偏差统计、整体评价
- **单价异常清单** — 红黄标注，含建议
- **指标分析** — 指标对比表

同时生成 Markdown 聊天摘要，可选生成视频报告。

## 内置知识库

### 材料参考价格（河南省2026年基准）
- 商品混凝土 C15-C50: 380-650 元/m³
- 钢筋 HRB400: 3580-4050 元/t
- 型钢 Q235B/Q355B: 4200-5200 元/t
- 水泥/砂/碎石/砌块/防水/涂料/电缆/管材等

### 综合单价合理区间
- 土方工程/混凝土工程/钢筋工程/钢结构/砌体/防水/装饰/安装等 21 类

### 工程量指标
- 工业建筑（破碎楼/转运站/钢结构厂房）
- 民用建筑（住宅/公建）
