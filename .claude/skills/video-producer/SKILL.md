# 视频制作 Skill

根据用户提供的项目信息，自动完成：文案撰写 → TTS 语音 → 电影字幕视频 → 桌面快捷方式。

## 工作流程

### 第一步：收集信息

向用户收集以下信息（如果未提供）：

1. **项目背景**：什么项目？时间、地点、规模
2. **关键数据**：工程造价金额、工程类型、单体数量等
3. **故事情节**：有什么特别的经历？（加班、困难、客户反馈等）
4. **公司信息**：公司名称、主营业务、slogan
5. **文案要求**：字数要求、风格偏好

### 第二步：撰写专业文案

根据收集的信息，写一篇不少于 2000 字的专业文案。要求：

- 使用工程造价行业的专业语言
- 分章节叙事（项目背景 → 技术难点 → 工作过程 → 成果交付 → 价值升华）
- 有温度、有细节、有专业度
- 适合配音朗读（句子不宜过长）

将文案保存为 Markdown 文件。

### 第三步：拆解为视频场景

将文案拆分为 10-20 个场景，每个场景是一个独立的旁白段落。场景类型：

- `title`：片头
- `scene`：正常叙事
- `highlight`：重点强调
- `closing`：片尾

### 第四步：生成视频

使用视频生成脚本。脚本位置：本 skill 目录下的 `generate_video.py`。

**重要：** 文案内容需要内嵌到脚本的 `SCENES` 列表中。每个场景是一个 `(类型, 旁白文本)` 元组。

修改 `generate_video.py` 中的 `SCENES` 列表，填入新项目的场景内容。

运行脚本：
```bash
PYTHONIOENCODING=utf-8 python3 <skill_dir>/generate_video.py
```

### 第五步：验证并交付

1. 确认视频文件已生成到 `C:\Users\Administrator\Videos\中联永信\`
2. 确认桌面快捷方式已创建
3. 用系统播放器打开视频预览
4. 告知用户文件位置和桌面快捷方式

## 技术栈

- **文案**：AI 生成，专业工程造价语言
- **画面**：Pillow 渲染，深蓝金商务配色
- **配音**：Microsoft Edge TTS（zh-CN-YunxiNeural 男声），免费
- **字幕**：底部居中，逐词高亮，电影风格描边
- **合成**：moviepy + ffmpeg，1920×1080 H.264

## 输出位置

- 视频：`C:\Users\Administrator\Videos\中联永信\<项目名>.mp4`
- 桌面快捷方式：`<桌面>\中联永信宣传片-<项目名>.url`
