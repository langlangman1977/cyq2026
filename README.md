## 智能体：造价清单审核助手

一个具备20年工程造价经验的AI智能体，用于审核工程量清单的单价合理性。

## 功能模块

### 📊 清单审核 Tab
- 上传 Excel 格式的工程量清单（支持拖拽）
- 选择建筑类型（工业建筑/民用建筑）
- 输入项目名称和建筑面积（可选）
- 一键审核：逐条分析单价、工程量指标、材料价格
- 结果展示：偏差清单（红/黄标注）、指标卡片
- 下载审核报告 Excel 文件

### 🔍 材料查询 Tab
- 输入材料名称查询市场参考价
- 支持地区筛选

### 🧠 记忆库 Tab
- 查看记忆库统计（已审项目数、已记子目类型数）
- 查看已审项目列表
- 按子目名称召回历史均价

## 后台引擎

### zaojia_auditor.py
- Excel 清单解析（自动识别表头）
- 单价审核（内置30+种材料价格库 + 21类子目单价区间）
- 工程量指标分析（钢筋含量、混凝土含量、平米造价等）
- 生成3 Sheet审核报告Excel（审核摘要/单价异常清单/指标分析）

### list_memory.py
- 记住每次审核的清单数据
- 积累为审核知识库
- 支持按子目名称召回历史均价
